# 00 — Contexto general

Estoy desarrollando la práctica **WaterManagement** de Sistemas Distribuidos. Revisa primero el repositorio y trabaja sobre su implementación actual.

El sistema está dividido en `WM_Central`, `WM_FO`, `WM_WS_E` y `WM_WS_M`. Utiliza Python 3.12, Kafka (`kafka-python`), SQLite, sockets TCP y Docker.

Implementa o modifica únicamente lo necesario para cumplir el enunciado. Mantén los nombres, argumentos, topics y formatos de mensajes existentes. No añadas tecnologías ni interfaces web que no estén en el proyecto. Explica brevemente los cambios y cómo probarlos.
